# Wallpaper Generator v2.1

A modern, web-based procedural wallpaper generator. Create beautiful, high-quality, abstract wallpapers for your desktop or mobile devices with a click of a button!

## Features

- **Real-time Procedural Generation**: Instantly generate wallpapers using Canvas API and Simplex Noise.
- **7 Modern Generator Styles**:
  - ✨ **Aura Mesh**: Glassmorphic, soft glowing orbs.
  - 🌐 **Cyberpunk Grid**: Synthwave wireframe landscape with a glowing sun.
  - 🗺️ **Topography**: Clean, minimalist isometric contour lines.
  - 🌌 **Cosmic Nebula**: Deep space fractal gas clouds and stars.
  - 📈 **Random Scribbles**: Chaotic, sweeping, overlapping curved lines.
  - ⛰️ **Grassy Hills**: Smooth, rolling mountains with procedurally generated grassy ridges and a distant sun.
  - 🌅 **Sea Sunset**: Beautiful horizon with dynamic ocean waves, clouds, and birds.
- **Curated Color Palettes**: Hand-crafted palettes ranging from Pastel Aura and Neon Cyberpunk to Deep Forest and Monochrome Slate. All palettes are arranged sequentially to simulate atmospheric depth.
- **Export**: Instantly download your generated creations as high-resolution PNGs.
- **Responsive UI**: Sleek, dark-mode user interface that works on both desktop and mobile.

## Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Zustand** (State Management)
- **Simplex Noise** (Procedural generation)
- **Lucide React** (Icons)

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
